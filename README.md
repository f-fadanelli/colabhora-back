# 🤝 Colabhora - Comunidade de troca de serviços

Repositório contendo um serviço de APIs para uma aplicação de troca de serviços entre membros da comunidade.

A aplicação permite que usuários ofereçam e solicitem serviços dentro de uma comunidade, promovendo colaboração, economia solidária e conexões locais.

---

## 🚀 Tecnologias Utilizadas

- **Node.js**
- **TypeScript**
- **Express**
- **JWT** para autenticação
- **PostgreSQL**
